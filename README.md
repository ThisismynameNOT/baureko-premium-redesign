# BAUREKO Premium Redesign

Procurement-ready construction and engineering website demo using verified company facts and clearly disclosed illustrative content.

## Local preview

```bash
npm install
npm run build
npm run dev
```

The checked-in `dist/` folder can also be hosted directly on GitHub Pages, Netlify, Vercel, or any static web host.

## Quality checks

```bash
npm run lint
npm run validate:html
npm test
```

## Production handoff

- Replace demo form handling with the client's approved email endpoint or CRM.
- Confirm all contact and legal details with the company.
- Replace editorial/illustrative artwork with licensed company photography where indicated.
- Replace the canonical placeholder domain before launch.
- Add the client's analytics and consent configuration only after approval.
